# Galactic Harmony - Overview.md

> 本文件是給老師、組員與展示觀眾閱讀的遊戲總覽。  
> 本版本由原本《Orbital Hunter / Gravity Drift》的太空引力漂移概念改造而來，保留原本的 2.5D 太空飛行、行星引力、Boost、雷達、鏡頭與科幻 UI，但核心玩法改為「限時救援女團成員」。

---

## 一、專案定位

《Galactic Harmony》是一款使用 JavaFX 製作的 2.5D 太空救援遊戲。

玩家駕駛太空飛船，在固定大小的星系地圖中，依靠行星引力、飛船慣性、Boost 加速、聲音辨位與雙層雷達，在 60 秒內尋找並救援散落在各星球附近的女團成員。

遊戲的重點不是大型宇宙探索，而是一個短時間、高回饋、可展示的完整關卡：

```text
開始任務 → 60 秒倒數 → 聲音與雷達找人 → 救援成員 → 避開敵人 → 保持 HP → 最後救援觸發慢動作 → 結算評級
```

---

## 二、與原始 Inspiration.mdc 的關係

原始 Inspiration.mdc 的核心是：

- 太空漂移感
- 引力彈弓
- 行星作為地形
- 雷達探索
- Boost 加速
- 高速甩尾
- 科幻 HUD
- 第三人稱追尾鏡頭

新版不刪除這些設計，而是將「摧毀敵方據點」改成「救援女團成員」。

也就是說：

| 原始設計 | 新版 Galactic Harmony |
|---|---|
| 找敵方據點 | 找散落在星球附近的女團成員 |
| 摧毀核心 | 觸碰並救援成員 |
| 雷達追蹤據點訊號 | 雷達與歌聲追蹤成員 |
| 戰鬥破壞感 | 救援與保護隊伍感 |
| 據點爆炸結算 | 最後救援慢動作 + 結算評級 |
| 漂移加分 | 漂移仍保留為操作與展示亮點 |

---

## 三、遊戲目標

關卡開始後啟動 60 秒嚴格倒數。  
玩家需要在時間內盡可能救援所有女團成員，並維持飛船 HP 大於 0。

勝利與評級不只看救援人數，也看剩餘血量。

---

## 四、評分與評級系統

滿血為 5 顆心。  
最終評級依照「成功解救比例」與「剩餘 HP」共同判定。

若飛船 HP 歸 0，不論救到幾人，皆為 F。  
若解救人數為 0，也為 F。

| 評級 | 條件 |
|---|---|
| S | 解救 100% 成員，且 HP = 5 |
| A | 解救 100% 成員且 HP = 3~4；或解救 80% 以上且 HP = 4~5 |
| B | 解救 80% 以上且 HP = 1~2；或解救 50%~79% 且 HP = 3~5 |
| C | 解救 50%~79% 且 HP = 1~2；或解救低於 50% 但至少 1 人，且 HP > 0 |
| F | HP = 0，或解救人數 = 0 |

結算畫面必須讀取真實遊戲資料，不可使用假數據。

## 五、完整遊戲流程

```text
主選單
  ↓
開始任務
  ↓
60 秒倒數開始
  ↓
玩家利用外圈雷達與歌聲尋找女團成員
  ↓
靠近半徑 50 內，成員顯現並出現歌聲
  ↓
玩家用飛船本體或後方隊伍碰到成員，完成救援
  ↓
成員加入飛船隊伍，頭像出現在 UI
  ↓
敵人與子彈干擾玩家
  ↓
玩家被擊中時扣 HP，並永久流失最後救援的成員
  ↓
救到最後一名可救援成員時觸發 Bullet Time
  ↓
慢動作漂移 2.5 秒
  ↓
淡出進入結算畫面
```

## 六、玩家飛船設計

玩家操控一架太空戰機。

### 操作

| 操作 | 功能 |
|---|---|
| WASD / 方向鍵 | 控制飛船移動方向 |
| Shift | Boost 加速 |
| Space / 滑鼠左鍵 | 射擊敵人或防禦裝置 |
| 雷達觀察 | 尋找敵人、子彈與成員方向 |
| 聲音辨位 | 依歌聲音量與聲波 UI 找到目標 |

### 飛船特性

1. **HP 系統**  
   飛船滿血為 5 顆心，被敵人子彈或敵人碰撞擊中時扣 1 顆心。

2. **Inertia Surfing**  
   飛船受慣性影響，不會立即停止或轉向，呈現太空滑行感。

3. **Boost 加速**  
   Boost 是有限資源，用於高速移動、逃離危險、貼近行星甩尾。

4. **Drift Mechanics**  
   飄移與旋轉不以機鼻為中心，而是偏向飛船尾部或一角作為視覺軸心，讓轉向更像高速甩尾。

5. **尾翼與殘影特效**  
   只有在按下 Shift 或觸發大角度飄移時，尾翼才會產生強烈推進與殘影。

6. **Snake Hitbox**  
   飛船本體與已救援成員形成一條隊伍。  
   只要飛船或隊伍任何一處碰到未救援成員，即救援成功。  
   但敵人子彈打到飛船本體或後方隊伍，也都算玩家受傷。

## 七、女團成員 Idol 系統

### 1. 群集生成

一個星球對應一個女團。  
每個星球可在其引力圈、軌道或周邊星塵中生成多名該團成員。

新版明確規則：要救援的歌手不是生成在行星內部，也不能被行星球體遮住。  
每位 Idol 都是環繞行星運動的軌道物體，位於行星半徑之外的安全軌道帶上，會以自己的軌道半徑、初始角度與角速度繞母行星移動。

展示版視覺規格：救援目標必須是一個個清楚可見的球形物體。  
球形 Idol 在未救援前會持續繞星球運行，玩家只有讓飛船本體或後方救援隊伍實際碰到球體，才算救援成功；單純進入偵測範圍只會強化雷達與聲音提示，不會自動救援。

球形 Idol 的表皮必須來自 `src/main/resources/photo`。  
同一顆星球對應同一個 IdolGroup，也必須使用同一張 photo 圖片作為所有該團球形救援目標的表皮；不同星球可使用不同圖片。

例如：

```text
Planet A → Group A 的 3 名成員
Planet B → Group B 的 4 名成員
Planet C → Group C 的 2 名成員
```

### 2. 隱藏與偵測

每位 Idol 一開始是隱藏狀態。  
玩家進入半徑 50 內後，該 Idol 顯現，並開始播放對應歌曲提示。

### 3. 音量與距離

距離越近，音量越大。  
設計概念：

```text
每靠近 Idol 5 單位，聲音大小 +5
```

### 4. 同團音樂防重疊

為避免同一女團多名成員同時造成同一首歌多軌重疊，系統對每個女團只播放「距離玩家最近的那一位未救援成員」的歌聲。

也就是：

```text
同一女團多名 Idol 靠近玩家 → 只取最近者計算音量
不同女團同時靠近玩家 → 可同時聽到多首歌
```

### 5. 登船與伴唱

救援成功後，該 Idol 會加入飛船隊伍。  
UI 顯示該成員頭像。

航行期間，已救援成員會隨機開口唱歌。  
唱歌時，該成員 UI 頭像發光。

### 6. 受擊永久流失

玩家被敵人擊中時：

1. HP 扣 1。
2. 觸發強烈畫面震動。
3. 若隊伍中有已救援 Idol，最後救援的 Idol 被撞飛。
4. 該 Idol 播放「啊啊啊啊~~~」語音。
5. 撞飛後化為星塵消失或飛出畫面。
6. 該 Idol 無法再次救援。
7. 玩家本局最高可救援人數永久減少，評級會受到影響。

這讓救援不只是收集，也包含保護隊伍的壓力。

## 八、行星與場景

行星仍保留原本設計：不是背景，而是地形與玩法機關。

### 行星功能

1. 具有 3D 立體外觀。
2. 可使用女團 Logo 或主題視覺。
3. 每顆行星內部管理其對應女團成員清單。
4. 提供引力彈弓效果。
5. 提供排斥力場，避免玩家撞星球死亡。
6. 可作為敵人、成員與路線規劃的空間參考。

### 行星公轉

除中央恆星外，所有行星都必須以恆星為中心慢慢公轉。  
展示版的行星公轉半徑必須改為目前生成半徑的 0.6 倍，也就是先依原本規則決定行星位置，再把該行星相對恆星的距離縮放成 60%。  
公轉速度要慢，讓玩家能看出星系在動，但不能快到影響救援可讀性。

### 行星公轉避讓

當兩顆行星距離低於安全距離時，軌道位置較後方的行星會暫停公轉。  
暫停期間行星仍會自轉、保留引力與碰撞，只是不沿軌道前進。  
直到兩顆行星距離重新大於恢復距離，暫停行星才重新公轉。

### 飛船撞行星

飛船接觸行星表面或近表面碰撞圈時不會直接死亡，但必須扣 1 顆心。  
撞擊後飛船會被排斥力場推出行星表面，並有短暫無敵時間，避免同一次碰撞在同一秒內連續扣血。

### 航道邊界

地圖具有固定大小。  
當飛船超出畫布邊界時，不直接死亡，而是：

```text
顯示「你已脫離航道！」
給予減速阻力或回推力
```

## 九、敵人與子彈

敵人是靜態射擊型，具有固定守備領域。展示版敵方單位數量要大幅增加，每顆行星周圍形成多座衛星砲塔群，讓救援路線需要穿越真正有壓力的防線。

### 敵人屬性

- 固定位置或小範圍巡邏。
- 擁有中距離 Aggro Zone，玩家靠近戰區時才開火，避免全地圖追擊。
- 擁有 HP，例如 3 點生命值。
- 玩家進入範圍後射擊，且會依玩家速度預判瞄準。
- 敵人射擊間隔比上一版延長 1 秒，讓彈幕壓力下降。
- 敵人子彈速度較快，精準度高，但仍保留少量誤差讓玩家可以靠 Boost、行星掩護與漂移躲避。
- 敵人必須使用 JavaFX primitive shapes 建立程序化 3D 模型，不依賴 OBJ 或外部模型檔。
- 敵人外觀是科幻浮空衛星砲塔：發光 Sphere 核心、旋轉外圈與四向砲管。
- 不顯示敵方單位的 Aggro 領域，避免畫面被大型範圍提示蓋住。
- 射擊前核心短暫變亮，射擊瞬間砲口 flash；被擊中時閃紅或閃白；HP 歸零時播放簡單爆炸後移除。
- 敵方數量配置以「每顆行星多座守衛」為基準，而不是單顆星球只放一個敵人。
- 玩家子彈有效距離只應略長於敵人射程，讓玩家需要接近戰區才能清除砲塔，不可再用超遠距離安全掃射。

### 玩家消滅敵人方式

1. **射擊消滅**  
   玩家子彈打中敵人，敵人 HP -1。  
   敵人 HP <= 0 後爆炸並移除。

2. **碰撞消滅**  
   飛船本體或後方隊伍撞到敵人也可以消滅敵人。  
   但這是危險行為，會同時觸發玩家受傷判定。

### 玩家受傷條件

以下情況皆算受傷：

- 敵方子彈打中飛船本體。
- 敵方子彈打中後方 Idol 隊伍。
- 飛船本體撞到敵人。
- 後方 Idol 隊伍撞到敵人。

受傷效果：

```text
HP -1
Camera Shake
最後救援 Idol 永久流失
```

### 子彈撞行星或恆星

不論玩家子彈或敵人子彈，碰到行星或恆星地形時不可反彈。  
正確行為：

```text
子彈碰到行星 / 恆星 → 火花特效 → 子彈消失
```

這個判定必須發生在物理排斥力之前；子彈一旦接觸行星半徑，就標記為死亡並從場景移除，不能被行星力場推開或繼續飛行。

### 恆星外觀

中央恆星必須是不透明、非常明亮的發光球體。  
主色調必須是暖色橘色。  
它可以使用自發光材質或高亮材質，但不可半透明、不可暗沉，且仍然作為子彈碰撞會消失的地形。

### 子彈與排斥力場

子彈不是飛船，不可受到行星或恆星的排斥力場、引力彈弓或危險區推力影響。  
物理層必須先對子彈本幀飛行線段做碰撞掃描；只要線段碰到行星或恆星半徑，子彈立即消失。  
若沒有碰撞，子彈只沿自身速度直線前進，不可被 `dangerRadius` 彈開。

## 十、雙層雷達系統

### 1. 內圈：危險警告雷達

內圈是實線圓形雷達。

當敵人或子彈進入危險範圍時，內圈對應方向亮紅光。

用途：

- 提醒敵人方向。
- 提醒敵方子彈來向。
- 高速飛行時提供危險感知。

### 2. 外圈：歌手探測雷達

外圈是向外擴散的脈衝波紋，參考《薩爾達傳說：曠野之息》的神廟雷達。

距離最近目標 Idol 越近：

- 波紋擴散速度越快。
- 振幅越大。
- 聲音提示越明顯。

### 3. 防呆提示

玩家太久找不到目標時，系統播放提示音，並可短暫加強脈衝雷達強度，引導玩家回到正確方向。

## 十二、音效與音樂

音效是核心玩法的一部分。

### 音效設計

1. **Ambient Base Track**  
   宇宙環境底層音樂，例如低音節拍或心跳聲。

2. **K-Pop 歌聲提示**  
   玩家接近 Idol 時，對應女團歌曲漸漸變大。

   展示版先使用 `src/main/resources/music` 中唯一的 mp3 檔案作為所有女團的共用歌曲。  
   每個 IdolGroup 仍保留固定歌曲對應關係，之後可替換成不同 mp3；目前全部指向同一首 `supernova.mp3`。

   對應成員的音樂音量必須與當下外圈雷達脈衝 / 震動強度等比改變。  
   越接近該團最近未救援 Idol，雷達震動越強，該團歌曲音量也越大；距離遠時音量降低。

   音量必須是更明顯的線性關係：雷達完全沒有感測到 Idol 時，對應歌曲音量為 0 並停止播放；進入雷達感測範圍後，依距離線性增加音量，越靠近越大聲。

3. **環境音自動淡出**  
   當玩家靠近 Idol，K-Pop 歌曲變大時，環境音樂自動 Fade-out，讓聲音焦點轉向歌手。

4. **多女團混音**  
   不同女團可同時發聲，但同一女團只播放最近成員，避免 Echo Bug。

5. **流失語音**  
   Idol 被擊飛時播放「啊啊啊啊~~~」。

6. **戰鬥與危險音效**  
   包含射擊、受擊、Boost、行星危險、警告提示等。

## 十三、Bullet Time 結算演出

當玩家碰到最後一名可救援 Idol，達成勝利條件時，不立刻切畫面。

系統會進入結束停格：

```text
ENDING_FREEZE 0.15 秒停格
播放 impact 音效
不再進入結算前 Bullet Time
直接淡出到獨立 Result Screen
Result Screen 讀取 ScoreResult，依序跳動顯示 rescue、lost、HP、ratio
所有數字完成後延遲 0.3 秒顯示 Rating
```

這是展示時的重要視覺亮點。

音效規則：

- 結束停格播放 resources/music 內的 impact sfx。
- Result 數字跳動播放 tick sfx，但限制每 0.04~0.08 秒一次，不能每幀播放。
- Rating 根據 F / C / B / A / S 播放不同強度 reveal 音效。
- 不使用任何受版權保護作品的素材或名稱，只做高能量戰鬥結束節奏。

## 十四、展示版必做功能

### 必做

1. 60 秒倒數。
2. HP 5 顆心。
3. 多名 Idol 分布在多顆星球附近。
4. 半徑 50 偵測與顯現。
5. 同團只播放最近 Idol 歌聲。
6. 觸碰救援。
7. RescueGroup 跟隨飛船。
8. Snake Hitbox 救援與受擊。
9. 受擊永久流失最後 Idol。
10. 靜態射擊敵人與敵方子彈。
