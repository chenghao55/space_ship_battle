# Kpop Universe
## 遊戲方式
- WASD / 方向鍵：控制飛船 
- Shift：Boost 
- E / 滑鼠左鍵：射擊
- ESC：暫停 
- F11 / Alt + Enter：全螢幕

## 執行方式
### 下載repository
1. 編譯環境
- maven
- JDK 21
- JavaFX 版本：21.0.6 (OpenJFX)
2. 程式入口
space_ship/src/main/java/com/binge/GameProject/Main.java
執行此class中的main()
