# Kpop Universe

## How to Play

* WASD / Arrow Keys: Control the spaceship
* Shift: Boost
* E / Left Mouse Button: Shoot
* ESC: Pause
* F11 / Alt + Enter: Fullscreen

## How to Run

### Download the Repository

1. Development Environment

* Maven
* JDK 21
* JavaFX version: 21.0.6 (OpenJFX)

2. Program Entry Point
   `space_ship/src/main/java/com/binge/GameProject/Main.java`

Run the `main()` method in this class.
